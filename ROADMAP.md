# Froja roadmap

Froja is an active work in progress. Priorities may change based on testing and community feedback.

## Release candidate

- Portable configuration and local model discovery.
- Windows and Linux setup packages.
- Standard, Z-Image Turbo, and Krea-2 workflow validation.
- History, Favorites, themes, accessibility, and localization foundation.
- GPU-memory handoff between isolated engines.

## Next

- First-run configuration wizard and dependency health dashboard.
- Per-model compatibility profiles and clearer workflow validation.
- Full image-to-image/inpainting mask editor.
- Improved ControlNet model selection.
- Non-destructive project files and reusable generation sessions.
- Search, tags, folders, and export in History/Favorites.
- More complete translations and screen-reader testing.
- Automated Windows/Linux release packaging.

## Later

- Plugin SDK and versioned workflow adapters.
- Optional remote ComfyUI connections with explicit security controls.
- Batch generation and comparison workspace.
- Metadata import/export and reproducible workflow bundles.
- Community style packs containing prompts only, never restricted weights.
