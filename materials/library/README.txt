Froja Local Material Library

Place your own PNG, JPG, JPEG, or WebP material reference images in this folder.
Froja does not copy, upload, or modify these files.

Optional sidecar metadata:
For brick.png, create brick.json with:
{
  "name": "Slumped Mortar Brick",
  "prompt": "dusty tan slumped mortar brick, loose mortar ridges, rough matte finish, chips and shallow cracks",
  "source": "https://polyhaven.com/a/slumped_mortar_brick (CC0)"
}

In Froja Training Studio > Appearance Library > Materials, click Rescan.
