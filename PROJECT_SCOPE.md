# Froja Project Scope

Froja Image Studio is an independent project rooted at this directory.

All Froja work must remain inside this directory except for explicitly configured external services and linked model libraries such as ComfyUI, Ollama, WanGP, checkpoints, LoRAs, VAEs, embeddings, and output folders.

Do not inspect or modify Jarvis Voice Assistant or sibling projects while implementing Froja features.

Current priority: complete and visibly test the integrated Froja Video Studio, including text-to-video, image-to-video, audio, playback, editing, and social-media export presets.
