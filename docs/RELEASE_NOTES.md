# Froja Image Studio v0.1.0 — Public Preview

The first public preview of Froja Image Studio brings a modern, local-first workspace to ComfyUI and user-owned model libraries.

## Included

- Text-to-image generation and linked model discovery.
- Checkpoint and LoRA previews, trigger words, and prompt tags.
- Z-Image Turbo and Krea-2 Turbo workflow adapters.
- Ollama prompt assistance and image-to-prompt recognition.
- Image enhancement, image-to-image, inpainting, ControlNet, IC-Light, repair, face, and JoyAI entry points.
- History, Favorites, zoom, themes, accessibility scaling, and localization foundation.
- Portable Windows/Linux configuration with no bundled model weights.
- Coordinated VRAM handoff between isolated ComfyUI engines.

## Before installing

Froja is an active work in progress. Advanced workflows require compatible third-party ComfyUI nodes and legally obtained model files. Read the model requirements and setup documentation in the repository.

Choose the Windows ZIP or Linux tar.gz package below. Packages contain empty model folders only; your private models remain yours.
