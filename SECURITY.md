# Security policy

Froja is designed for local use and binds to `127.0.0.1` by default. Do not expose its Python server or ComfyUI endpoints directly to an untrusted network.

Please report security issues privately through GitHub's security advisory feature rather than a public issue. Do not include tokens, personal images, private prompts, proprietary model weights, or unredacted machine paths.

Only the latest release receives security fixes during the pre-1.0 period.
